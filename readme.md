# 💡 Important Concepts

> Keep short explanations of concepts that I frequently forget.

* **Package:** A way to organize Go code.
* **`main` package:** Entry point package for an executable Go program.
* **`main()` function:** Execution starts here.
* **`fmt`:** Standard library package for formatted I/O.
* **`fmt.Println()`:** Prints text followed by a newline.
